# Video-Sharing-Platform
A full-stack video sharing platform built using the MERN stack that enables users to upload, manage, and watch videos through a modern web interface. The application includes secure JWT-based authentication, video uploads with Cloudinary, user profiles, comments and replies, likes/dislikes, channel subscriptions, and search functionality. 

## Features
- JWT Authentication
- Video Upload
- Comments & Replies
- Likes & Dislikes
- Channel Subscriptions
- MongoDB Aggregation
- Cloudinary Integration

## Tech Stack
- React
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
